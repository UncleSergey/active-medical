# Диагностика activemedical-dent.pp.ua

Проверено 24 августа 2026.

- DNS A: `185.176.43.100`
- HTTP: `http://activemedical-dent.pp.ua` отвечает `HTTP/1.1 200 OK`, сервер `Apache`, контент отдаётся с внешнего хостинга.
- HTTPS: проверка не проходит: `ERR_CERT_COMMON_NAME_INVALID`.
- Сертификат HTTPS: `CN=f28-preview.runhosting.com`; SAN содержит только `DNS:f28-preview.runhosting.com`, домен `activemedical-dent.pp.ua` отсутствует.
- Сертификат выдан Let's Encrypt, срок: 1 августа 2026 — 30 октября 2026.
- Вывод: домен сейчас указывает на внешний RunHosting (`185.176.43.100`), а не на Manus-проект. На сервере внешнего хостинга установлен сертификат для `f28-preview.runhosting.com`, поэтому браузер показывает предупреждение. HTTP фактически отвечает, но редирект HTTP→HTTPS не настроен/не может считаться безопасным до выпуска корректного сертификата для домена.
- Для исправления нужен доступ к панели внешнего хостинга, где домен привязан к сайту: добавить `activemedical-dent.pp.ua` как домен, выпустить Let's Encrypt для этого домена, затем включить принудительный редирект HTTP→HTTPS. Альтернатива — подключить домен к Manus через управление доменами и заменить DNS-записи по инструкции Manus.
